Destiny 6100  
Home Management Security System  

DESTINY 6100 - 16 zone Control / Communicator Home Management Security System. Includes control panel and transformer.

System

  • 16 hardwired zones on the system controller
  • Expandable to 96 hardwire / wireless zones
  • One 2-wire smoke loop
  • 410+ word vocabulary annunciated through keypad or phone
  • 4 words assigned per zone 
  • Annunciated alarm type and zone description during activation
  • Internal and external voice drivers 
  • 2 and 4 wire smoke detector support with smoke reset 
  • 512 event memory log
  • 8 area split-arming
  • Supports 8 addressable keypads
  • Phone line supervision
  • High current supervision
  • True battery test
  • Temporal fire tome annunciation

Local and Remote Phone Access

  • Answering machine override
  • Full system control including arming and disarming
  • Direct access to home control devices
  • Access to 2-way voice features, including homeowner listed-in
  • Answering service override

Programming

  • DOS-based installer programming software
  • All 100% Hayes-compatible modems supported
  • Remoted modem programming or direct programming through local phone jacks
  • Keypad or remote phone programming with full speech confirmation

Home Control

  • Phone / Keypad control of up to 56 lights and appliances (ON / OFF / DIM)
  • 8 chaining channels allowing 16 control activations based on one command
  • 4 Command sets: dimming, all lights on, all lights off, flash
  • Time of day operation
  • Day of the week programming schedules
  • Event driven control of lights / relays
  • Phone / Keypad control up to 56 relays: 7 low current relay activation pins plus 1 relay on the system controller, 8 additional relay outputs per EXP-8 relay expansion module
  • Manual or fully automatic operation
  • X-10 compatible

Central Station Communication

  • Formats include : 3x1, 4x1, 4x2, Ademco Contact ID
  • Failure to open / close reporting

2-way Alarm Verification

  • Enables the central station to verify alarm activity within a residence 
  • 3 individually controlled microphone channels
  • Adjustable sensitivity
  • Sirens muted during 2-way voice activation
  • Automatic activation after digital tranmission
  • Homeowner access to 2-way operation
  • Paging from local or remote telephone
  • Listen-in from local or remote phones

Power Specification

  • Watchdog circuitry insures integrity of mircoprocessor
  • 3 AMP power supply (2 AMPS auxiliary)
