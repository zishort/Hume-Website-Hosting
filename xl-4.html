XL-4 / XL-5  
Hybrid Control / Communicator  
  • 8 zone control / communicator
  • Hardware or multiplex expansion capabiliy
  • 72 zone capacity through multiplex expansion
  • Partitioning (up to eight separate subsystems)
  • 64 users code with seven authorization levels by user code
  • 4 digit or 7 digit user codes, systemwide option
  • Keypad and remote programming
  • Upload / download / remote commands with answering machine override
  • System log retains past 128 events with option to automatically transmit log to remote or local printer
  • Fuseless design eliminates unneccessary services calls
  • Master keypad design showing armed / disarmed status for all partitions - LED or LCD
  • Auto arming by day, by partition
  • A single program question enabling call even zones to be tamper zones all odd zones
  • A common area partition
  • Up to 40 trigger outputs
  • Two programmable entry / exit delay times
  • Two wire multiplex bus provides power and supervised data path between the control panel and the multiplex accessories
  • Convenient two conductor wiring of multiplex loops for easy installation
  • Programmable zone characteristic for each multiplex point
  • PID format simplifiers programming and provides complete reporting
  • Zone and keypads are assigned to the desired partition
  • Users codes can be assigned to multiple partitions
  • Partition descriptor, 16 characters, uniquely identifies each subsystem
  • Multi partition features allows secure operation of the system through any keypad by authorized user
  • Authorized users can alter partition assignments through the keypad
  • Programmable transfer of system activity to a remote or local printer, automatically on either a daily, weekly or monthly basis
  • Programmable 16 character descriptors for each of 72 zones or points
  • Selectable alarm (16) and trouble (8) types
  • Chime option by zone
  • Pulse count option by zone
  • Zone grouping capability allows creation of groups within each partition for the purpose of group bypass and alarm transmission
  • Transmission speeds includes 10PPS, 20PPS, 40PPS, 4x2, FBII Superfast, BFSK, ADEMCO Express and Point ID formats
  • Up to 16 keypads per system, (LED or LCD)
  • Relay expansion module allows five relays, eight boards per system
  • System stabilization during startup - allow motion detectors to stabilize during power up
  • System can include 2 wireless receivers for extended CS telephone or dual areas
  • Dual CS telephone numbers per area
  • Dual CS account numbers (3 or 4 digit) per area
  • Touch tone formats: ADEMCO CID, FBII superfast, extended or partial extended
